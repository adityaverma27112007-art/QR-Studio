# QR Studio

A browser-only React/Vite QR generator with URL, text, email, phone and Wi-Fi modes; live preview; visual presets; customization; validation; scan-reliability warnings; PNG/SVG export; clipboard copy; local recent history; dark mode; and responsive design.

## Run

`npm install`

`npm run dev`

## Build

`npm run build`

No backend or environment variables are required.
